# Usage
Launch all simulations:
```bash
make -j test
```

To launch only the testbench for cpu:
```bash
make -j test ONLY=cpu
```
# Requirements
- [uv](https://docs.astral.sh/uv/)
- [make](https://www.gnu.org/software/make/)
